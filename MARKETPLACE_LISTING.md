Obsidian Bridge — Marketplace Listing

Short description:
Obsidian Bridge integrates local Obsidian vaults into JetBrains IDEs: note indexing, wiki-link completion and navigation from code comments, backlinks, tags, a link graph and full-text search.

What's New in 2026.9.0
- Backlinks, Tags and Graph tool windows are now populated (link resolution by path, name or alias).
- Wiki-link gutter icons open the linked note; Search Vault searches note content with snippets.
- Re-indexing no longer duplicates notes and follows renames/moves/deletes; the index is thread-safe.
- Frontmatter parsing fixes (inline lists, quoted values, CRLF); settings validation and re-index on apply.
- Removed unimplemented options, services and extension points.

What's New in 2026.8.0
- The plugin is now completely free — all features unlocked, no license needed.
- Source code is now open source under Apache-2.0.
